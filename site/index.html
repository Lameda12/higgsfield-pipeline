How it works

Five steps, zero manual glue.

01

Scrape

Pulls name, price, tagline and key features from the product page via async httpx.

02

Generate copy

Claude writes 3–5 hook variants across different angles — problem/solution, social proof, curiosity.

03

Score & select

A heuristic scorer ranks variants and auto-picks the strongest hook.

04

Generate video

Calls the Higgsfield MCP server to render a short campaign clip from the winning copy.

05

Ship assets

Everything lands in outputs/<timestamp>/ — video, copy JSON, selected hook.

Usage

Install, set your keys, run.

install 
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env   # fill in ANTHROPIC_API_KEY
run 
pipeline run https://example.com/products/your-product

# dry run: scrape + copy only, no video
pipeline run https://example.com/products/your-product --dry-run

# also generate a product image
pipeline run https://example.com/products/your-product --image
